# Excel — ferramentas de apoio a projetos

Coleção de livros Excel com macros. Os nomes indicam aplicações relacionadas com quadros de pilares e listas de peças desenhadas; as fórmulas e macros internas ainda não foram verificadas.

## Requisitos e utilização inicial

Utilizar Excel desktop compatível com VBA. A compatibilidade com outras aplicações de folhas de cálculo, versões de Excel ou sistemas operativos não foi estabelecida.

1. Guardar uma cópia do livro original.
2. Abrir a cópia no Excel e identificar as folhas de entrada, fórmulas e resultados.
3. Inspecionar as macros e referências VBA antes de as ativar.
4. Substituir apenas as entradas identificadas, preservando fórmulas e formatação.
5. Comparar um exemplo conhecido antes de usar os resultados num projeto.

Não estão documentadas as células de entrada nem os nomes das macros; este README não inventa essas instruções.

## Manutenção

Exportar os módulos VBA para ficheiros de texto, documentar as entradas e dependências e incluir um exemplo sem dados de projeto. Isso permite rever alterações sem depender apenas do ficheiro binário.

## Validação

Para o quadro de pilares, documentar unidades, hipóteses e critérios técnicos realmente utilizados. Uma verificação de fórmulas/macros é diferente da validação de engenharia dos resultados.
